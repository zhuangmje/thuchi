Gắn link ảnh vào Sheet (hyperlink)

1) Giải nén ZIP, tải ảnh lên 1 thư mục Google Drive. 2) Trong Sheet: Tiện ích mở rộng → Apps Script, dán đoạn dưới, sửa ID thư mục và tên tab, bấm Chạy. Mỗi ảnh dong_N.jpg sẽ thành link “Xem ảnh” ở cột B dòng N tab hình ảnh.

function linkAnh(){
  const FOLDER='DÁN_ID_THƯ_MỤC_DRIVE';
  const sh=SpreadsheetApp.getActive()
    .getSheetByName('TÊN_TAB_HÌNH_ẢNH');
  const it=DriveApp.getFolderById(FOLDER).getFiles();
  while(it.hasNext()){
    const f=it.next();
    const m=f.getName().match(/^dong_(\d+)\./);
    if(!m) continue;
    sh.getRange(+m[1],2).setFormula(
      '=HYPERLINK("'+f.getUrl()+'","Xem ảnh")');
  }
}
